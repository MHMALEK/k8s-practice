# Lab 00 — Foundations

**Roadmap:** [Phase 0](../../docs/ROADMAP.md#phase-0--foundations)

## Goal

Get comfortable with the Linux CLI, basic networking ideas, Git, and YAML before containers.

## Prerequisites

- A terminal (macOS/Linux or WSL)
- Git installed

## Your artifacts

- `notes.md` — short definitions (process, port, DNS, YAML map vs list)
- Optional: `scripts/` — small practice scripts

## Exit criteria

You can explain DNS resolution and read simple YAML without confusion.

## Start with the teacher

> “I’m on Lab 00 — walk me through the first step only.”
